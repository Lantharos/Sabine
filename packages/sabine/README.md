# `@lantharos/sabine`

Typed helpers for pages running inside a Sabine window. Prefer these exports over reaching for
`window.sabine` directly.

## Install

```sh
bun add github:Lantharos/Sabine#v0.42
```

See the [web API guide](../../docs/web-api.md) for bridge commands, window controls, guests, native video and the rest of the page API.
